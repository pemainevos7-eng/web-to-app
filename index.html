HELP CENTER

Documentation

Panduan singkat penggunaan ZORA BUILDER.

01 — Configure your application

Masukkan alamat website lengkap dengan https://, nama aplikasi, package name, dan versi aplikasi. Package name harus unik, misalnya com.brand.aplikasi.

02 — Upload assets

Pilih icon dan splash screen dari perangkat. Gunakan gambar PNG, JPG, atau WebP. API saat ini membatasi string gambar Base64 hingga 25.000 karakter.

03 — Start build

Tekan Build Android APK. Server akan mengirim workflow_dispatch ke GitHub Actions. Status job dan langkah workflow diperbarui secara berkala.

04 — Download APK

Jika workflow selesai dengan sukses dan artifact tersedia, tombol download akan muncul. Jika build gagal, periksa detail workflow melalui tautan GitHub Actions.

Build requirements

  • Website dapat diakses melalui internet.
  • GitHub Actions workflow build.yml aktif.
  • Vercel environment variable GITHUB_TOKEN sudah dipasang.
  • Token GitHub memiliki izin Actions yang diperlukan.
  • api/build.js, api/status.js, dan api/download.js tersedia.
